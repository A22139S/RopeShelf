# 0.1.1 开发记录

- 增加缩略图磁盘缓存。以像素哈希定位缓存，并核对原图长度与修改时间；缓存损坏或原图改变时重新解码。重启30张图片的集成检查要求30次缓存命中。
- 增加拖放副本租约。七天内保留，启动时只清理有记录、无未知文件、路径归属校验通过的过期暂存目录。早期无记录副本保留。
- 补充回收中断恢复检查，证明不会覆盖仍存在的原图，重复备份保留到 Recovered。
- 修正恢复期间条目被移除或更新时的索引定位，避免使用旧记录的值相等性查找。
- 修正悬停与主动唤出的状态区分、新图覆盖主动展开、快捷键收起后热区立即重开三个问题；对应回归检查先失败后通过。
- 为已有卡片、设置和预览增加动态主题资源，监听系统偏好事件；深浅色/高对比度资源切换检查通过。
- 缓存目录创建或枚举失败时退化运行，不阻止收图或取下；清理失败与索引保存失败分别报告真实文件状态。
- 文件夹收图不再将原图重新编码为 PNG，只为剪贴板生成收件箱文件；复制和预览先核对尺寸再解码，降低峰值内存风险。
- 清除快捷键后不再尝试注册空键；无效录入不会覆盖上一个有效组合。
- 回收站检查仍未通过；独立 API、路径长度及回调探测见 recycle-diagnosis.md。未降低成功判定标准。
- 性能对比在8秒预热后采样8秒。正常轮询约0.39%单核，实验停用轮询约0.59%单核；初次启动短采样不代表稳定待机。临时停用开关已从生产路径移除，原始比较数据留在验证附件。

尚未宣称跨应用拖放、多缩放真实桌面及干净系统验收通过。原始需求与验收范围继续有效。
