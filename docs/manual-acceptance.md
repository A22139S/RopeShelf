# 0.1.1 手动验收

请先完成第一轮，再回传结果；通常需要10—15分钟。不需要发送真实截图或私人图片。

## 准备

1. 解压便携包全部文件到可写目录。如已有绳间运行，先从托盘退出，避免快捷键冲突。
2. 双击包内 `manual-check.cmd`。测试数据写入包旁的 `ManualTestData`，与默认使用数据分开。不要勾选开机启动。
3. 打开画图，画三个不同颜色的色块，分别保存为A、B、C三张测试图片。另建一个空文件夹作为接收目录。

测试启动器仍监听正常剪贴板和截图目录；测试期间只操作这些生成的图片。再次打开同一启动器会继续原测试记录。

## 第一轮：核心体验

| 编号 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 在画图打开A，Ctrl+A、Ctrl+C；重复复制一次 | 绳上出现一张A，同一图片短时间重复复制不增加卡片；新图短暂展示后收起 |
| 2 | 鼠标停在主屏顶部中央约0.3秒；移到卡片上，再移开 | 展开；指针在卡片上时不收起，离开后收起；Ctrl+Alt+T也能展开和收起 |
| 3 | 在记事本连续输入，使用顶部悬停展开，再继续输入 | 记事本继续收到输入，浮层不抢键盘焦点 |
| 4 | 单击A；切到画图新画布并粘贴 | 粘贴完整图片；绳上不因自身复制多出一张 |
| 5 | 双击A；返回后中键点A，再按Esc | 默认图片应用打开A；中键显示预览，Esc关闭预览 |
| 6 | Win+Shift+S截取生成的色块；再用Win+PrintScreen截取测试桌面 | 两种来源都能收图；同一截图同时经目录和剪贴板到达时只出现一张。记录每种快捷键是否真的生成了图片或文件 |
| 7 | 向两个实际应用拖入卡片，例如画图和Word；只拖入文档，不提交或发送消息 | 两个应用都收到可打开的完整图片，绳上原卡片保留。请记下应用名称和版本 |
| 8 | 将一张卡片拖进接收目录 | 文件生成且可打开；成功后卡片取下。若文件已生成但卡片保留，记录浮层提示，仍判此项未通过 |
| 9 | 对另一张卡片右键另存到接收目录，然后尝试取下剩余测试卡片 | 另存图片可打开；自管图片取下后能在系统回收站找到并还原。取下失败时原图应仍能打开；不要把“文件消失”直接记作成功 |
| 10 | 留两张卡片，托盘退出，再双击同一测试启动器 | 卡片恢复，图片可复制和打开；退出后托盘和浮层消失 |

第8、9项是当前重点：开发环境尚未取得回收站成功证据，可能出现“文件已保存、卡片取下失败”。请保留准确提示。卡片右键“打开所在文件夹”可确认其原文件；应用日志位于 `ManualTestData\logs`，回传错误行即可。

## 第二轮：系统集成

第一轮通过后再进行；没有对应设备或环境的项目填“未测”。

- 第三方截图工具：使用你平时的截图工具截取生成的色块，确认到达且显示正确；记录工具名称及版本。若同时保存文件与复制图片，同一截图只应出现一张。
- 过滤：分别复制记事本文字、Excel单元格、资源管理器中的图片文件列表，卡片数不应增加；在画图复制像素图片则应增加或按短时间去重规则合并。Excel单元格即使附带位图格式也不应被当作截图。
- 目录：托盘设置添加一个测试目录，再把B、C复制进去；各出现一张。取下这些外部卡片后，目录原文件仍存在。
- 目录边界：先把A放进一个尚未监视的测试目录，再添加该目录，旧A不应自动挂上；添加后再保存B应挂上。在保存完成后重命名B，不应凭重复通知再出现一张。
- 容量与中断：只用可丢弃的测试图，连续收集31张不同图片，最新30张顺序正确。外部目录原图应全保留；剪贴板自管图片超限时最旧一张应能在回收站找到。若容量超过30张且出现回收失败提示，记为失败。随后从任务管理器结束本次测试的RopeShelf进程，再用同一启动器重开，检查记录和图片能恢复；不要结束其他进程。
- Explorer：分别拖入同盘和另一块盘的目录，文件可打开，卡片取下；拖放中按Esc取消，卡片和原文件保留。没有第二块盘填未测。
- 空白穿透：在记事本或可滚动网页上方展开绳子，在卡片以外的透明空白处点击和滚轮操作，下方应用应收到事件；卡片自身则可点击、滚动浏览。收起后同一位置不应残留遮挡。右键菜单保持打开或正在拖放时，绳子不应提前收起。
- 缩放：在100%、125%、150%、200%下分别检查顶部位置、卡片清晰度、点击位置和横向滚动。更改后按系统提示处理，不以单一缩放推断其他比例。
- 多屏：切换主显示器后，浮层转到新主屏且不越界；休眠唤醒后仍能收图和展开。
- 全屏：在全屏应用中产生测试截图，应收图但不自动弹出；Ctrl+Alt+T能主动展开。记录应用和全屏类型，浏览器F11不能证明独占全屏通过。
- 主题：在程序运行时切换系统浅色、深色和高对比度；已有卡片、设置与预览文字应清晰。
- 快捷键冲突：用另一测试程序占用设定快捷键，设置应反馈失败；改回有效组合后能唤出。
- 开机启动：仅在愿意注销/重启时测试。勾选后重新登录应驻留托盘；取消后再次登录不自动启动。
- 干净系统：在没有安装.NET的Windows 11 x64测试机或VM解压启动。当前设备上随包运行时启动成功不能替代此项。
